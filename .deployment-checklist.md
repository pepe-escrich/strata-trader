# ✅ Deployment Checklist

## Pre-Deployment

- [ ] Todo el código está commiteado y pusheado a GitHub
- [ ] Tests pasan (si existen)
- [ ] `.env` files NO están en git (solo `.env.example`)
- [ ] Ejecutado `./scripts/verify-deployment.sh` sin errores
- [ ] README y documentación actualizados

## Backend (Render)

- [ ] Cuenta de Render creada
- [ ] Repositorio conectado
- [ ] Servicio web creado
- [ ] Variables de entorno configuradas:
  - [ ] `NODE_ENV=production`
  - [ ] `PORT=3000`
  - [ ] `API_PREFIX=api`
  - [ ] `BINGX_API_KEY` (opcional)
  - [ ] `BINGX_SECRET_KEY` (opcional)
  - [ ] Otras variables según `.env.production.example`
- [ ] Build exitoso
- [ ] Health check funciona: `https://tu-api.onrender.com/api/health`
- [ ] Market endpoints funcionan: `https://tu-api.onrender.com/api/market/symbols`

## Frontend (Vercel)

- [ ] URL del backend de Render copiada
- [ ] `frontend/src/environments/environment.production.ts` actualizado con URL correcta
- [ ] Cambios commiteados y pusheados
- [ ] Cuenta de Vercel creada
- [ ] Repositorio conectado
- [ ] Proyecto creado con configuración correcta:
  - [ ] Framework: Angular
  - [ ] Root Directory: `frontend`
  - [ ] Build Command: `npm run build`
  - [ ] Output Directory: `dist/frontend/browser`
- [ ] Build exitoso
- [ ] App carga correctamente en el navegador
- [ ] No hay errores CORS en consola
- [ ] Dashboard muestra datos de mercado

## Post-Deployment

- [ ] Ambos servicios están "Live" y funcionando
- [ ] Frontend conecta correctamente con Backend
- [ ] Datos de mercado se actualizan automáticamente
- [ ] No hay errores en logs de Render
- [ ] No hay errores en consola del navegador
- [ ] URLs guardadas para referencia:
  - Backend: `https://_____.onrender.com`
  - Frontend: `https://_____.vercel.app`

## Opcional

- [ ] Dominio personalizado configurado
- [ ] MongoDB Atlas configurado (para persistencia)
- [ ] Monitoring configurado (Sentry, LogRocket, etc.)
- [ ] Analytics configurado (Google Analytics, Vercel Analytics)
- [ ] SSL/HTTPS funcionando correctamente
- [ ] Documentación actualizada con URLs de producción

## Notas

**Render Free Tier:**
- Se duerme después de 15 minutos de inactividad
- Primera request puede tardar ~1 minuto
- Para evitar esto, considera Render Starter ($7/mes)

**Vercel Free Tier:**
- Despliegues ilimitados
- 100 GB bandwidth/mes
- Ideal para proyectos personales

## Troubleshooting

Si algo no funciona:
1. Revisa logs en Render Dashboard
2. Revisa consola del navegador (F12)
3. Verifica CORS configuration en `backend/src/main.ts`
4. Verifica que API URL en frontend sea correcta
5. Consulta [DEPLOYMENT.md](DEPLOYMENT.md) para soluciones comunes
